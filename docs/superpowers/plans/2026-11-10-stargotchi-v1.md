# StarGotchi v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A virtual-pet firmware ("StarGotchi") for the Waveshare ESP32-S3-Touch-AMOLED-1.75 with one evolving bot, a tilt-controlled mini-game, sounds, and a browser installer on GitHub Pages.

**Architecture:** Pure C++ game logic (`src/game`, `src/storage`) with no Arduino dependencies, unit-tested with g++ in CI. A thin hardware layer (`src/hal`) wraps the vendor drivers; an LVGL 8 UI layer (`src/ui`) renders it. CI builds with arduino-cli and deploys an ESP Web Tools installer page to GitHub Pages.

**Tech Stack:** ESP32 Arduino core 3.3.10, LVGL 8.4.0, GFX Library for Arduino 1.6.4, SensorLib 0.3.1, XPowersLib 0.2.6, arduino-cli, GitHub Actions, GitHub Pages, ESP Web Tools, Python 3 + Pillow (asset tool).

**Spec:** `docs/superpowers/specs/2026-11-10-stargotchi-v1-design.md`

**Hardware reference:** `github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75` — `HARDWARE_REFERENCE.md`, `examples/arduino/06_LVGL_Widgets` (display/touch/IMU init), `08_ES8311` (audio), `03_LVGL_PCF85063_simpleTime` (RTC), `05_LVGL_AXP2101_ADC_Data` (power). Copy init sequences from these; do not invent register values.

## Global Constraints

- No protected names, logos or characters anywhere (code, assets, strings, docs): no "Star Wars", "Droid", "Jedi", "Lightsaber", no original characters. Creatures are "bots"/"units".
- Product name: `StarGotchi`. All on-device text is English.
- Board: ESP32-S3R8, 16 MB flash, OPI PSRAM. FQBN: `esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi,CDCOnBoot=cdc`.
- Display 466×466 CO5300: `new Arduino_CO5300(bus, 39, 0, 466, 466, 6, 0, 0, 0)` on QSPI CS 12, SCK 38, D0–D3 = 4,5,6,7. LVGL flush areas rounded to even start / odd end (Waveshare `rounder_cb`).
- Shared I2C: SDA 15, SCL 14. Touch CST9217 @0x5A, INT 11, RST 40, `setMaxCoordinates(466,466)`, `setMirrorXY(true,true)`. QMI8658 @0x6B. PCF85063 @0x51. AXP2101 @0x34. ES8311 @0x18.
- Audio I2S: MCLK 42, BCLK 9, WS 45, data-out 8, PA enable GPIO 46 HIGH.
- Stats are floats 0–100. Decay per hour awake: oil −4, mood −5, power −3, cond −2. Asleep (night or docked): oil −2, mood −2.5, cond −1, power +10.
- Night = local hour ≥ 22 or < 7. RTC holds local wall-clock time; all timestamps are "local seconds since 1970".
- Evolution by age: Core → Mini at 1 day, → Junior at 3 days, → final form at 7 days.
- Shutdown: ≥ 2 stats at 0 continuously for 8 hours. Reboot halves XP, keeps stage.
- Actions: oil +30, repair +40 cond, each +10 XP. Level = 1 + xp / 100.
- Display: dim after 30 s idle, off after 60 s; a touch while dim/off only wakes.
- Save every 60 s and after every action. Installer updates must not erase the save.
- Fonts: LVGL built-in `lv_font_unscii_16` and `lv_font_unscii_8` only (pixel look). Background pure black.
- Colors: oil `#EF9F27`, mood `#D85A30`, power `#5DCAA5`, cond `#378ADD`, holo text `#85B7EB`, muted `#B4B2A9`, track `#2C2C2A`.

## Review Focus

1. Updating through the installer must keep the bot: the manifest must flash bootloader/partitions/boot_app0/app as separate parts and never touch the NVS range `0x9000–0xDFFF` (Task 1 check script).
2. RTC reset or clock moved backwards (e.g. dead battery → year 2000): no negative decay, no instant evolution; time older than 2025 means "ask for time" (Task 2 test `time_backwards_is_ignored`, Task 9).
3. Long offline gaps (weeks): catch-up is capped at 30 days, finishes fast, and correctly triggers shutdown (Task 3 test `month_offline_triggers_shutdown`).
4. Offline gap spanning night: night hours use asleep rates (Task 2 test `offline_overnight_uses_sleep_rates`).
5. Tap that wakes a dark screen must not also press a button (Task 6 test `wake_touch_is_consumed`).
